# CLAUDE.md — контекст проекта

## Что это
Локальная программа для юриста, работающая с договорами в Word. Две задачи:
1. **Протокол разногласий** (готово). Берёт договор с правками Word и строит протокол разногласий по шаблону.
2. **Итоговая редакция** (готово, идёт приёмка). Обратная задача: исходный договор + протокол разногласий (docx или скан) и/или допсоглашения → договор в итоговой редакции с редлайном (`w:ins`/`w:del`, автор правки = документ-источник). Программа понимает автонумерацию Word.

Плюс **история** всех прогонов обеих вкладок в папке `Архив/` с открытием в Finder.

## Текущая задача
- ТЗ: `docs/итоговая-редакция/ТЗ.md`
- План и статусы этапов: `docs/итоговая-редакция/ПЛАН.md`. После каждого этапа отмечай статус.
- Этапы 0–7 готовы, этап 8 (приёмка) ждёт проверки в Word пользователем.
- Ключ Gemini уже лежит в `.env`. Никогда не читай и не выводи его значение; проверять можно только наличие строки (`grep -c '^GEMINI_API_KEY=' .env`) и связь (`gemini.ping()`).

## Правила
- Только стандартная библиотека Python 3, без pip и внешних зависимостей. Gemini вызывается через `urllib`.
- Сервер слушает только `127.0.0.1`. В сеть ходит только `gemini.py` и только по явному действию пользователя.
- Логику **вкладки 1** (протокол) правь в обоих файлах: `protocol_app.py` и `Протокол разногласий.html`. **Новая вкладка и история** есть только в `protocol_app.py`, HTML не трогаем.
- Ключ Gemini хранится только в `.env` (в .gitignore). Его нельзя показывать в UI, логах, архиве или чате.
- Договоры — конфиденциальные данные: не коммитить (`Договор_*.docx`, `Архив/` в .gitignore).
- Тексты интерфейса и комментарии пиши на русском.

## Карта файлов
| Путь | Назначение |
|---|---|
| `protocol_app.py` | Сервер (`Handler`, все `/api/...`), логика вкладки 1 (`parse_contract`, `build_protocol`) |
| `page.html` | Интерфейс Python-версии: 3 вкладки + настройки (HTML/CSS/JS) |
| `sources.py` | Источник (docx-протокол / ДС / скан) → правки: выбирает локальный разбор или Gemini |
| `Протокол разногласий.html` | Автономная браузерная версия вкладки 1 (JS-копия логики) |
| `Запустить.command` | Запуск двойным щелчком на macOS |
| `docxcore.py` | Общее: загрузка/сохранение `document.xml` без потери пространств имён, абзацы, текст редакции, нормализация |
| `numbering.py` | Вычисление номеров абзацев: автонумерация (`numbering.xml`, `styles.xml`) и текстовая нумерация |
| `edits.py` | Модель правки, разбор протокола docx, разбор ДС по типовым формулировкам (без сети) |
| `redline.py` | Применение правок правками Word (`build_final`), сопоставление с договором (`Applier.locate`), `contract_info`, для тестов `reject_all` / `view_paragraphs` |
| `gemini.py` | Клиент Gemini: сканы и свободный текст ДС → JSON-правки (промпт, `EDIT_SCHEMA`) |
| `history.py` | Архив прогонов, `meta.json`, открытие в Finder |
| `config.py` | Чтение и запись `.env` |
| `tests/` | `unittest`; фикстуры — `tests/fixtures/` (синтетические docx генерируются в тестах) |
| `docs/итоговая-редакция/` | ТЗ и план |
| `docs/шаблон_протокола_разногласий.docx` | Шаблон протокола (вкладка 1); ищется в корне, затем в `docs/` |
| `docs/Договор_товарищество_обезличенный.docx` | Образец договора с правками (текстовая нумерация) — основа round-trip-теста |
| `tests/docgen.py` | Генератор синтетических docx (в т. ч. с автонумерацией) |

## Рабочие файлы во время работы программы
- `.env`: `GEMINI_API_KEY`, `GEMINI_MODEL` (права 600, в .gitignore).
- `Архив/ГГГГ-ММ-ДД_ЧЧММСС_<договор>/`: `вход/`, `результат/`, `отчёт.md`, `meta.json` (в .gitignore). Путь переопределяется `ARCHIVE_DIR` (для проверок — не засоряй настоящий архив).
- `docs/Договор_товарищество — исходник (тест).docx`, `… — итоговая редакция (тест).docx` — результат round-trip для проверки в Word (в .gitignore по маске `Договор_*.docx`).

## Важные детали реализации
- Имена файлов на macOS бывают в NFD — сравнивать через `unicodedata.normalize("NFC", …)`.
- Применение правок одного источника: поиск заменяемых/удаляемых пунктов — по нумерации ДО источника; место вставки — по текущей нумерации (правки идут сверху вниз, поэтому номера выше уже «новые»).
- Сквозная проверка: `RoundTripTest` в `tests/test_redline.py` (договор с правками → протокол вкладки 1 → применение к исходнику → сравнение принятого текста).

## Команды
- Запуск: `python3 protocol_app.py` (флаг `--no-browser` — без открытия браузера)
- Тесты: `python3 -m unittest discover tests`
- Живой тест Gemini (синтетика, без договоров): `RUN_GEMINI=1 python3 -m unittest discover tests -k Live`
- Проверка UI без засорения архива: `ARCHIVE_DIR=<scratch> python3 protocol_app.py --no-browser` (порт — первый свободный с 8765)
