# Протокол разногласий из правок Word

Программа превращает правки контрагента в режиме рецензирования Word в протокол разногласий по шаблону.

- Показывает пункты договора с правками: «было» и «стало», изменённые места подсвечены.
- Галочкой выбираете, какие пункты включить в протокол.
- По кнопке создаёт протокол разногласий в Word по шаблону.

Работает только на вашем компьютере: файлы никуда не отправляются, нейросети не используются.

## Вариант 1. Без установки (рекомендуется)

1. Скачайте файл **`Протокол разногласий.html`**.
2. Откройте его двойным щелчком: он откроется в браузере (Chrome, Edge, Firefox, Safari 16.4+).
3. Перетащите договор с правками (.docx) в рамку.
4. Заполните поля, отметьте пункты и нажмите «Создать протокол разногласий». Файл сохранится в «Загрузки».

Шаблон протокола уже встроен в файл. Другой шаблон можно выбрать кнопкой «Выбрать другой шаблон».
Странице запрещены любые сетевые запросы, поэтому она технически не может никуда отправить документы.

## Вариант 2. Версия на Python (для Mac)

Нужен Python 3, сторонние библиотеки не нужны.

- Дважды щёлкните **`Запустить.command`** (при первом запуске: правая кнопка → «Открыть»), или
- в Терминале: `python3 protocol_app.py`

Откроется страница в браузере. Шаблон берётся из файла `шаблон_протокола_разногласий.docx` в той же папке.

## Требования к шаблону

- Поля вида `{{название договора}}`: программа найдёт их сама и покажет для заполнения.
- Таблица из 3 колонок с заголовком «Редакция …» (№ пункта / Редакция Стороны-1 / Редакция Стороны-2): в неё добавляются строки с пунктами.

## Как программа оформляет пункты

- Новый пункт: в колонке Стороны-1 «Отсутствует».
- Удалённый пункт: в колонке Стороны-2 «Исключить».
- Если контрагент разбил или объединил пункты, они выводятся одной строкой, например «7.2 (7.2, 7.3 в редакции Стороны-2)».
- Добавленный текст выделяется жирным в колонке Стороны-2.
- Изменения только форматирования и правки в сносках не учитываются.
